# Text Convertor 📝

A simple and interactive **Text Convertor Web App** that allows users to input text and apply various styling transformations such as uppercase/lowercase conversion, font customization, color selection, and text shadow effects.

## ✨ Features

- ✅ Convert text to **UPPERCASE** or **lowercase**
- ✅ Change **font family**
- ✅ Adjust **font size** using a slider
- ✅ Apply **Bold**, **Italic**, and **Underline** styles
- ✅ Select custom **text color**
- ✅ Choose from different **text shadow** styles
